# 奥术学徒

致敬《神秘时代 4》的点击式网页小游戏。从砍树开始，逐渐解锁奥术研究、炼金、精华蒸馏、注魔和魔像自动采集。

- 「笔记」收录研究前置条件、元素组合、物品来源和各工作台配方。
- 研究笔记有两个固定要素。选中要素后可以放入任意空格，再点一次即可取回。沿相邻六边格把两端连通即可完成研究，相邻要素须互为成分与化合物。
- 完成「精华蒸馏」研究后，在奥术工作台制作蒸馏器、精华罐和蒸馏炉。蒸馏材料或坩埚精华时，每批消耗一份燃料，每种待储存的精华需要一个可重复使用的罐。
- 注魔祭坛消耗材料和罐装精华。蒸馏与注魔的剩余时间随存档保存。
- 木、陶、铁和符文魔像依次解锁。分配任务后会自动采集相应资源，地点污染时会暂停。
- 在「合成」（含熔炉）、「奥术工作台」、「坩埚」或「注魔祭坛」选择配方，展开「委托制作」，选好魔像并填写成品数量。木、陶、铁、符文魔像分别能处理最多 1、2、3、4 层制作。采集原料不计入层数，成品配方和各级中间配方各占一层。比如符文魔像制作注魔基座时，可以逐层补齐奥术石块、神秘金属锭和铁锭。魔像优先使用背包材料，并按需采集和加工。缺设备、研究、工具或魔力时会显示等待原因。完成或取消委托后，魔像会恢复原来的采集任务。
- 在魔像页展开每只魔像的「工坊设备」，可用背包里的设备安装专用坩埚、蒸馏器或注魔祭坛，也可将专用设备里的精华转为研究灵感。专用坩埚和蒸馏器负责制备精华，专用祭坛负责注魔，个人坩埚、蒸馏装置和祭坛可同时使用。
- 探索过异域第 2、3 层后，符文魔像可分别经虚空裂隙采集奥术石英和虚空灵液，用于后期委托。
- 点击顶部「污染」或世界页的「洗去污染」，可以用清水、圣水或净化浴降低环境污染。点击受污染的地块可以恢复该处的采集。
- 点击顶部「扭曲」可以查看永久、普通和临时扭曲。永久与普通扭曲合计超过 10 点后，扭曲事件会揭示「净化浴盐」研究，完成后可研究「祛邪肥皂」。每块肥皂搓洗 10 秒，清除全部临时扭曲，有 33% 的几率洗去 1 点普通扭曲。扭曲守护和在圣水中搓洗各增加 25 个百分点。永久扭曲会保留。

进度保存在浏览器本地存储中。

在页面底部点击「导出 JSON」即可下载当前进度。点击「导入 JSON」选择备份文件，确认覆盖后，进度会立即恢复并保存到当前浏览器。旧存档中的精华保存在坩埚里，可以转移到蒸馏炉装罐。
