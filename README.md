# 奥术学徒

致敬《神秘时代 4》的纯鼠标网页小游戏。从砍树开始，经过扫描、研究、坩埚、奥术工作台、注魔、节点、污染与魔像，一路走到虚空金属。

进度保存在浏览器本地存储中。

在页面底部点击「导出 JSON」即可下载当前进度。点击「导入 JSON」选择备份文件，确认覆盖后，进度会立即恢复并保存到当前浏览器。

## 像素材质

游戏使用下列授权贴图。各文件的来源、裁剪、着色和图层记录见 [材质清单](assets/textures/sources.json)。

- Minecraft Java Edition 1.7.10，Mojang Studios 和 Microsoft。[Minecraft](https://www.minecraft.net/)
- Thaumcraft 4.2.3.5，Azanor 与原素材贡献者。[CurseForge](https://www.curseforge.com/minecraft/mc-mods/thaumcraft/files/2227552)
- Thaumic Tinkerer 2.5-512，Thaumic Tinkerer 作者及贡献者。[项目资料](https://www.curseforge.com/minecraft/mc-mods/thaumic-tinkerer) · [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/)
- 补充贴图来自本项目的原创图标，以及 Kenney Vleugels 和 Lynn Evers 的 CC0 素材。部分 CC0 贴图经过配色或组合。[Roguelike/RPG Pack](https://opengameart.org/content/roguelikerpg-pack-1700-tiles) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

预览时将 `assets/` 与 `index.html` 一起保留。补充图集 `assets/pixel-art/icons.png` 每格为 16×16 像素，对应的 `icons.js` 按行记录图标 ID。
